# 冷启动与交互提取验收清单（Windows 优先）

## 自动化验证

- [ ] `pnpm test` 通过（含 `src/config/*.test.ts` 新增用例）
- [ ] `openloom setup --non-interactive` 退出码为 0
- [ ] `openloom roots set <path>` 后 `openloom roots show` 返回同一路径
- [ ] `openloom roots clear` 后 `openloom roots show` 显示未配置

## 手动流程验证

### 1. 首次 setup

- [ ] 删除测试目录中的 `.openloom` 后执行 `openloom setup`
- [ ] setup 可提问用户称呼、agent 称呼、风格、输出偏好，并允许输入 `skip`
- [ ] 生成 `.openloom/agent/lessons.md`
- [ ] 生成 `.openloom/config/user-settings.json`
- [ ] `initialized=true`，并写入 `initialized_at`

### 2. extract 交互模式

- [ ] 在未初始化状态执行 `openloom extract --interactive <path>` 会自动触发 setup
- [ ] 交互提问可设置 OCR provider / 人脸检测 / 并发参数
- [ ] 任务完成后输出统计 summary

### 3. 兼容性与回归

- [ ] 非交互命令 `openloom extract <path>` 仍可运行
- [ ] 既有 `.openloom/metadata/*` 结构与内容格式未变化
- [ ] hash-skip 与路径刷新行为无回归（参考 `docs/metadata-regression-report.md`）
